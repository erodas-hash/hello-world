# Tablero de Seguimiento de Proyectos

Aplicativo web sencillo para registrar proyectos y monitorear indicadores de gestión:

- Avance planificado.
- Avance real.
- Porcentaje de ejecución frente al plan.
- Costo planificado.
- Costo real.
- Estado del proyecto.

## Uso

Abre `index.html` en un navegador. El tablero incluye datos de demostración, permite agregar nuevos proyectos, eliminar registros y restaurar la información demo.

Los cambios se guardan en `localStorage`, por lo que permanecen disponibles en el mismo navegador.
